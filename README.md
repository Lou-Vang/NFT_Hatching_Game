# NFT Hatching Game

Blockchain-based NFT animal hatching game with verifiable rarity and ownership.

Our project is an NFT Hatching Game built on the Ethereum Sepolia test network. NFT stands for Non-Fungible Token, meaning each animal is a unique digital asset stored on the blockchain with verifiable ownership and rarity.

## Project Purpose

Traditional digital games often rely on centralized systems where rarity, ownership, or item generation can potentially be manipulated. Our project addresses this issue by using Ethereum smart contracts to create a transparent and tamper-resistant NFT hatching system.

Players purchase digital eggs, hatch unique animals with randomly generated rarity levels, and receive blockchain-verified ownership of their NFTs.

The project demonstrates:

- Blockchain-based NFT ownership
- Random rarity generation using smart contracts
- Cross-contract communication
- Tamper-resistant on-chain records
- Transparent and fair rarity systems
- Optional NFT marketplace trading

## Features

- Purchase digital eggs
- Hatch unique NFT animals
- Random rarity generation
- Blockchain ownership verification
- On-chain NFT storage
- Marketplace trading support
- Transparent smart contract interactions

## Smart Contracts

### EggContract
Handles egg purchases and validates player transactions.

### HatchContract
Generates random animals and rarity levels during the hatching process.

### NFTContract
Mints NFTs, stores ownership on-chain, and supports future transfers or trading.

## Stakeholders

### Player
Purchases eggs, hatches NFT animals, owns digital assets, and may trade NFTs with other players.

### Smart Contract System
Executes blockchain logic, validates transactions, generates random rarity levels, mints NFTs, and manages ownership records.

### Marketplace (Optional)
Allows players to list, trade, sell, or transfer NFT animals between users.

### Ethereum Blockchain Network
Stores NFT ownership, rarity data, and transaction history in a decentralised and tamper-resistant manner.

## Business Process Overview

1. Player purchases an egg
2. Payment and eligibility are validated
3. Hatch request is sent to the smart contract
4. Smart contract generates rarity and animal traits
5. NFT is minted and ownership is assigned
6. NFT is stored on-chain
7. Optional marketplace trading can occur
